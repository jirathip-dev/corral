## Scope — `src/transcript/` module ONLY

No HTTP endpoint, no UI, no session discovery. Public surface:

```rust
pub enum StoreRef { Opencode { session_id: String }, Claude { jsonl_path: PathBuf }, Codex { rollout_path: PathBuf } }
pub struct Entry { pub role: String, pub text: String, pub ts: u64 }
pub struct TranscriptPage { pub entries: Vec<Entry>, pub next_cursor: Option<Cursor> }
pub async fn read_page(store: &StoreRef, cursor: Option<&Cursor>, limit: usize) -> Result<TranscriptPage, TranscriptError>
```

(Adjust shapes if the code demands it — say so in the report.)

- Newest-first paging; page cap: min(limit, 50) entries AND a 256 KiB text
  budget per page.
- **opencode**: sqlite3 CLI shell-out exactly like `src/cost/opencode.rs`
  (mode=ro, busy timeout, JSON output, every query bounded in SQL by
  session id + time/id cursor over `message`/`part`). NO sqlite crate — no
  new dependencies at all.
- **claude/codex jsonl**: read backwards from EOF in bounded chunks (seek;
  never read the whole file), parse only the requested page. The cursor is
  a byte offset (+ line disambiguator if needed).
- **Redaction inside the module boundary**: every Entry.text passes the
  D-083 rules via `src/core/redact.rs` BEFORE it leaves the module. If the
  existing redact API doesn't fit, extend it additively — do not fork the
  rules.
- Typed `TranscriptError` (store unreadable / bad cursor / sqlite3 binary
  missing), no unwrap/expect on malformed stores.

## Tests — at minimum

Fixture-driven (temp dirs; build tiny opencode.db fixtures with the
`sqlite3` CLI in the test, skipping cleanly if the binary is absent —
follow how src/cost tests handle this): paging walks a multi-page fixture
newest-first with no gaps/duplicates; the 256 KiB budget truncates a page
without dropping entries silently (cursor resumes correctly); seeded
secrets (sk-ant-…, ghp_…, AKIA…) are redacted in returned pages for EVERY
store kind; opencode opened read-only (pin the `mode=ro` invocation);
malformed jsonl lines are skipped with a typed note, not a panic; a 100MB
synthetic jsonl opens its newest page without reading the file (bound the
bytes read — assert via chunk accounting, not wall-clock).
