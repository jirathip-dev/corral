## Proven defect boundary

The old client created `URLSessionWebSocketTask` from the host URL before rejecting an unavailable worktree, and passed the host URL directly to the WebSocket factory. The production regression test therefore reached the crash boundary instead of only checking capability availability. The fix validates the worktree and cancellation state before opening a socket, normalizes HTTP(S) hosts to WS(S), and turns connection/protocol/handshake failures into typed errors.

This proves the reachable simulator/test-process boundary. The physical-device cause remains unknown until the human gate above is performed.

- Production lifecycle seam: `TerminalAttachLifecycleRegressionTests` calls `TerminalAttachClient.connect` and `TerminalAttachSessionModel`, not just capability predicates.
- Success/error/cancel/dismiss/retry: explicit connecting, connected, and failed states; streamed frame/cursor updates; Retry starts a new generation; Done and disappearance cancel/close; cancellation suppresses late updates.
- Failure handling: unavailable worktree, invalid host, encoding, handshake timeout, server refusal, network failure, malformed/out-of-order/binary messages, and command failures are surfaced without force unwraps, swallowed client errors, or fatal paths. Failed UI includes Retry and Done.
