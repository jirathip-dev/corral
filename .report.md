## Spec reading (documented, testable)

"Done section renders ONLY when herdr reports done (wire-done ranked with idle otherwise)"
is client-ambiguous — wire-`done` and herdr-`done` are the same `AgentState` enum value.
Implemented reading (recorded in `BoardModel` doc comments + lane notes): the canonical
bucket list is `[blocked, working, idle, done, unknown]`, each rendered only when non-empty,
so a Done section appears exactly when the daemon reports a done agent (herdr 0.8.2
finished panes fall back to idle, so live boards show only the four locked sections); done
sits after idle (rank-2 tie per `contracts/state-tokens.json`) and before unknown.
`testDoneGetsItsOwnSectionOnlyWhenHerdrReportsIt` and
`testDoneSectionPositionIsRankTieNotTimestampDriven` pin both behaviors.
