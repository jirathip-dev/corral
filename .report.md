## Removal inventory

- `clients/egui/src/protocol.rs`: removed plugin card/action/view types, plugin GET/POST requests, and retired fleet-identity request plus ApplyMsg variants.
- `clients/egui/src/state.rs`: removed plugin and retired fleet-identity state and reducers.
