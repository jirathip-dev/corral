# impl-284 report

## Change

`clients/egui/src/main.rs` now selects the runtime icon by target OS:

- macOS embeds `assets/icon/corral-icon-macos.png`, the existing transparent
  1024x1024 rounded-squircle source.
- non-macOS native builds retain the existing opaque
  `assets/icon/corral-icon-256.png` behavior.
- wasm remains unaffected by the existing native cfg gate.

This is the smallest fix at the runtime override: the macOS bundle asset was
already correct, so no artwork or packaging asset needed regeneration. The
explicit Linux branch preserves its prior behavior.

The existing viewport test was renamed to
`viewport_builder_applies_platform_icon` and now checks the platform-specific
size. A macOS-only regression test checks alpha 0 at all four corners and
alpha 255 at the center.
