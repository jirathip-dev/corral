# #207 implementation report

## Change

The native GitHub plane now hydrates `IssuesCache` for every emitted `GhRepoState`, keyed by its native `repo` identity. The obsolete optional `issue_repo`/`issues_key` seam was removed from the event/spec contracts. `/issues` documentation now describes the native identity contract. The two existing cache tests were updated to prove both native identity and hydration for a non-fleet tracked repository.

No egui files, Fleet Ops/plugin code, or request-path subprocesses were changed.
