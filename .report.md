  `prompt` / `approve` / `interrupt` / `kill` / `attach` /
  `start_worktree` / `read_issues` arms, the approval-claim seam, the
  step-up gate, the worktree route, and every helper only they used.
  Kept: `read_tail`, `read_diff` (signed, granted, replay-claimed,
  audited) and the typed error mapping.
- **Capability contract** (`src/drive/mod.rs`): `Capability` is now a
  closed two-variant set `{ReadTail, ReadDiff}`; `FromStr` refuses every
  legacy name; `DrivePayload` trimmed to the read payloads. Removed
  names fail as `unknown_capability` BEFORE the authorizer, dispatch,
  and audit.
- **Approval plane**: `src/approve/mod.rs` deleted (claim identity,
  prompt-hash validation, choice validation). The one kept consumer
  (`approval_id_for` format in `src/push/mod.rs` history rendering)
  inlines the `"agent:hash"` format.
- **Step-up**: `src/auth/step_up.rs` deleted, `POST /step-up` route
  removed from `src/auth/http.rs`, AuthPlane doc/mentions updated.
- **Terminal/attach transport**: `src/tmux.rs` deleted; the
  `/v1/terminal` socket route was not present in this tree (attach was
  drive-plane only); herdr adapter attach/kill/prompt/approve adapter
  RPCs and their terminal_ref handling removed.
- **Fleet/worktree module**: `src/fleet/` (`mod.rs`, `worktree.rs`)
  deleted; `dispatch_worktree` route gone from `src/api/mod.rs`; the
  admin worktree projection rows removed.
- **Tests**: `tests/terminal.rs`, `tests/worktree.rs` deleted;
  `tests/drive.rs`, `tests/auth.rs`, `tests/provenance.rs`,
  `tests/model.rs` rewritten to the read-only surface.
