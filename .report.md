## Theme token map summary (semantic → palette token per flavor)

- Hierarchy: board/list/sheet surface = base; chrome strips/nav-adjacent =
  mantle; section-header strips = mantle; rows = base; tool chips = surface1
  at opacity; chip borders = surface1.
- Text: primary = text; secondary/meta = subtext1; quiet/tertiary (tail
  gutter, pane refs) = tailQuiet (overlay0 dark flavors / overlay2 Latte).
- State (locked): working=teal, blocked=red, done=green, idle=subtext0,
  unknown=surface2.
- Accent (UI): mauve of the active flavor (chips selected, live dot, pull
  icon, form checkmarks, buttons). Working state = teal ONLY; ANSI cyan
  slot also maps to the teal token (terminal-data semantics, per the
  approved ANSI table).
- Roles (rail markers): user=blue, agent=mauve(accent), tool=peach,
  system/unknown=muted.
- Tail panel: dark flavors = mantle; Latte = base (recess rule). Tail ink =
  text; tail muted = subtext0 (subtext1 on Latte).
- Repos: fnv1a32%8 over [blue, sapphire, teal, green, yellow, peach, mauve,
  pink] with linear-probe collisions; no repo = surface2.
- ANSI: slot table per design round (Latte arm: black=subtext1, white=
  subtext0, brightWhite=subtext1; dark arm: black=surface1, white=subtext1,
  brightWhite=subtext0; accents map to red/green/yellow/blue/pink(magenta)/
  teal(cyan); brightBlack=overlay1 both arms).
