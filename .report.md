## Module surface (`src/transcript/mod.rs`)

- `StoreRef::{Opencode{db_path, session_id}, Claude{jsonl_path}, Codex{rollout_path}}`
  — the brief sketched `Opencode{session_id}` alone; the db path is a
  parameter so the reader is fixture-testable and multi-store-capable
  (DEVIATION, flagged).
- `Entry { role, text, ts: Option<u64> }` — `ts` is `Option`: stores with
  string-only timestamps yield `None` in slice 1 rather than pulling in a
  date-parsing dependency (DEVIATION from the sketched `ts: u64`, flagged).
- `Cursor::{Opencode{time_created, id}, Bytes{offset}}`,
  `TranscriptPage { entries, next_cursor, skipped }` — `skipped` is the
  honesty counter for torn/malformed lines passed over.
- `read_page(store, cursor, limit)` — newest-first; caps: 50 entries AND
  256KiB text per page, budget-truncation resumes exactly (never drops).

## Cursor design

- opencode: strict `(time_created, id)` descending keyset pagination,
  bounded in SQL (`LIMIT`, session-scoped, cursor in the WHERE clause);
  sqlite3 CLI with `-readonly` + busy timeout (argv pinned by test).
  SQL literals are single-quote-escaped (no CLI bind params); pinned by a
  quoting test.
- claude/codex JSONL: byte-offset cursor, read BACKWARDS. Each call reads
  ONE tail range capped at 256KiB + 4×64KiB; if the range can't fill the
  page, a SHORT page returns with a resuming cursor — every call bounded,
  the walk complete. Pinned by a ~21MB fixture asserting the first page's
  cursor stays inside the cap (an exact observable, not wall-clock).

## Redaction wiring + the perf fix this surfaced

Every `Entry.text` passes `core::redact::redact()` INSIDE the module.
Doing so surfaced a pre-existing O(n²): `high_entropy_at` rescanned the
same alphanumeric run from every position — 35s (measured) for one 64KiB
unbroken blob, exactly transcript-shaped content, making AC3 (<2s)
unreachable. Fixed in `core/redact.rs` with a run-memoization whose
correctness argument is in the comment (a failed run cannot match from any
interior start: suffixes are shorter with a subset of character classes;
the other two matchers reject interior positions O(1) via boundary
checks). All 23 pre-existing redact behavior tests pass unchanged; a
regression test pins the linear bound (64KiB blob < 1.5s debug; actual
~ms). **This touches shared security code — priority review target.**
