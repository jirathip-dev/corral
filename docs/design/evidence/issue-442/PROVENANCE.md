## Horse artwork is original

Every horse pixel in this evidence package is generated by
`scripts/horsesvg.py`, written from scratch in this lane as flat vector
SVG (path/rect/circle/ellipse primitives only). There are no embedded
bitmaps, no fonts, no traced images, no imported SVG files, and no
assets copied from any other project.

- Source: `scripts/horsesvg.py` (SHA-256 in `manifest.sha256`).
- Author: this design lane (Hermes designer profile), 2026-09-08.
- License: same as the corral repository (the file carries no third-party
  code).
- Not used: herdr-mise kitchen sprites/vocabulary/layout (the issue names
  it as concept inspiration only — "agent monitoring can be playful" — and
  nothing was read from its assets); provider or model mascots/logos
  (harness strings such as `claude-code`, `codex`, `opencode` appear only
  as plain text in the detail-sheet subline and never drive species,
  coat, tack, or any visual treatment).

### Identity is deterministic and provider-agnostic

`fixtures.horse_identity(name)` = `sha256(agent_name)` bytes →
coat (8) × breed silhouette (3) × mane (3) × tack (3) × accessory (3).
The same lane name is the same horse in every state, palette, variant and
frame; `verify.py` probe P10 asserts the identity data-attributes are
byte-identical for each agent across all 21 stages. State changes pose
only (`horse_svg(identity, state, reduce_motion)`).

Coat/tack/accessory colors are fixed natural horse colors deliberately
outside the Catppuccin palettes (`horsesvg.py` constants) so identity
survives Mocha ↔ Latte. Everything else (sky, grass, fences, chips,
sheets, chrome) is a locked Catppuccin token or a documented mix of tokens.

## Theme tokens are the app's own

`fixtures.PALETTES` is the verbatim Mocha/Latte table from
`ios/FleetNotifier/UI/AppTheme.swift` (#372 lock). `fixtures.mix_hex` is a
port of `ThemeStore.mixedHex` (sRGB lerp, half-even rounding) and
reproduces the documented `#2e344d` Mocha blue-15%-over-base chip fill.
State→token (working=teal, blocked=red, done=green, idle=subtext0,
unknown=surface2), the mauve UI accent, the `RepoHue` FNV-1a ring, chip
mix ratios (17/34, 15/38, 9 %) and the #371 heartbeat timing (1.2 s cycle,
peak 42 %, 160 ms stagger) are all ported, not re-invented. Environment
colors (sky/grass/fence) are the only new derivations and are documented
in `build.palette_vars` as token mixes.

## Fixtures are fictional

All repositories (`project-hearthwild-monorepo`, `atlas-vector`,
`fern-quarry`, `orchard-lane`), lane names (tree/plant compounds:
`oak-before-dark`, `birch-clearing`, …), hosts (`mac-mini`, `bazzite` as
generic host labels), branches, and output lines in `scripts/fixtures.py`
are invented for this prototype. No real customer, staff, e-mail, domain,
credential or repository content appears. `verify.py` probe P12 scans every
generated HTML/MD/PY artifact against `fixtures.FORBIDDEN_STRINGS`.

## Renderer

Screenshots: `chrome-headless-shell` from the local Playwright cache
(`~/Library/Caches/ms-playwright/chromium_headless_shell-*/…`), one
invocation per stage at `--window-size=390,844
--force-device-scale-factor=2`, downscaled with macOS `sips` to exactly
390×844. `render.py` reads the PNG IHDR and refuses anything else.
R1 capture-only temporary CSS pauses animations before first paint at a fixed
500ms active time (delay -500ms); Reduce Motion animation:none is preserved.
Shipped HTML remains animated. `repro.py` captures isolated A/B runs, compares
every PNG byte and SHA-256, and promotes only compared bytes. See README and
logs/repro-red-green.log for the disposable mismatch discriminator.
