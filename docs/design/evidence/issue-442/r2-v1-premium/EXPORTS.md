# Separately addressable native/source exports

All exports are generated from retained editable `art.py` / `export-layers.py` and deterministic
fixture identities in `fixtures.py`. No external art dependency or generation service.
Run `python3 -B export-layers.py` from this directory. Every asset entry in `layers/index.json`
records exact dimensions/viewBox, z-index, anchor, composition rect/coordinate space,
parallax ratio, SHA-256, source generator and reproduction command. `layers/geometry.json`
provides measured viewport and every horse/nameplate/state rect, including off-screen paddocks.

## Inventory

74 SVG exports (verified independently):
- 12 environment layers: 6 each for Day/Night (sky, hills, ground, barn/trees, rear fences,
  foreground grass/light/grain). All 390×640 viewBox, scaled to the measured pasture rect.
- 1 blocked foreground rail: 390×44; position from geometry.
- 36 identity exports: 12 fixtures × body, grounding, moon-rim.
- 12 pose exports: standing, weight shift, grazing, intentional Reduce Motion standing ×
  body, grounding, moon-rim. Every sprite viewBox 148×112.
- 12 square-safe horse selections: 256×256 SVG, plus one 1024×768 editable 4×3 lineup.

Source z sequence: sky 0, hills 10, ground 20, barn/trees 30, rear fence 40,
foreground material/grass 50, horse grounding 55, horse body 60, moon rim 61,
blocked front rail 80, native labels/HUD above those. This is logical native layer order,
not the proof's small CSS stacking-context integers. Scene ratio values are proposed native
parallax, not an already animated screenshot. UI/rail stays fixed; see native contract.

Environment layers retain inline SVG filters and embedded deterministic RGBA paint. They
are standalone SVG files, not purely path-only vector art. Native platforms do not directly
render arbitrary browser SVG filters: rasterize exported SVGs at build time for SpriteKit,
or port the documented deterministic source to Swift/Canvas. Layers can be reconstructed
as one vector scene graph; the browser equality proof uses that route to avoid individual
raster alpha-edge rounding. Coat paint is generated by Pillow from analytic depth/light and
seeded material noise, embedded as base64 PNG; source is editable, no external raster source.

## Horse separation and lighting

Body SVGs exclude contact-shadow and moon-rim paths. Grounding and rim files retain the
matching facing transform, viewBox, source UID and anchor; overlay without recentering.
Day uses body + grounding, no moon rim. Night applies brightness .86 / saturation .82
as a whole-horse color treatment and adds the exported moon rim in original alignment.
The proof also mirrors its cast-shadow path with translate(135,0) scale(-1,1) at Night;
apply that only to `.cast-shadow`, inside the existing facing transform. Contact ellipses
stay planted. Never mirror the full horse merely to redirect a shadow.

## Future icon SOURCE ONLY

`layers/square/<agent>.svg` uses the same five identity axes and a calm standing silhouette.
No flags, labels, ground/shadows, app mask, icon background, icon wiring or existing icon input.
256×256 frame; safe rectangle [24,24]–[232,232]. Original 148×112 sprite is placed with
translate(24,49.2972972973), scale(1.4054054054054055). Frame bounds are recorded per asset;
source foot anchor is [74,107]. The lineup has 4 columns × 3 rows of these same 256px cells.
Individual SVGs—not a flattened lineup—are the source of truth for future candidate work.
Identity metadata names coat, breed, mane, tack and accessory. At very small future icon sizes,
simplification must be decided in that SEPARATE icon issue/gate, not silently done here.
