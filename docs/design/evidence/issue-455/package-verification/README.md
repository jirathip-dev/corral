# Promotion-time verification layer — issue #455 package

This directory records the verification performed when the approved #455
designer bundle was promoted into `docs/design/evidence/issue-455/`
(2026-09-12). It never modifies the retained 2026-09-09 prototype evidence in
`../evidence/`; old evidence and newly reproduced proof stay separate on
purpose.

## Provenance split

- `../index.html`, `../variant-a.html`, `../variant-b.html`, `../assets/`,
  `../evidence/`, `../references/`, `../README-designer-original.md`: the
  2026-09-09 designer-run artifacts, byte-identical to the frozen source
  bundle (verified against `../references/source-manifest.sha256` by
  `reconcile.py`; one whitespace-only normalization: `../evidence/run-log.txt`).
- This directory: 2026-09-12 promotion lane. All runs were executed from
  scratch copies (`/tmp/impl455-repro`, `/tmp/impl455-verify`) of the package;
  the read-only source bundle was never written to and the committed package
  was re-verified after every operation.
